# Laboratorio 3 - Árboles B

## Integrantes
- Yeferson Alexis Salcedo Preciado
- Samuel Velásquez Berrio
- Jonathan Alzate Castaño

## Descripción
Este proyecto corresponde al Laboratorio #3 de la materia Estructura de Datos.

Consiste en la implementación de un Árbol B que permite:

- Insertar nombres
- Buscar nombres
- Eliminar nombres
- Imprimir el árbol por niveles

El sistema garantiza el cumplimiento de todas las propiedades de balanceo del Árbol B y muestra trazabilidad de cada operación.
